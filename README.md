# Тестовое задание: Лендинг «Тысячелетний Брест»

Привет! Это репозиторий с выполненным тестовым заданием (верстка лендинга).

Рабочий проект можно посмотреть тут: [ссылка на GitHub Pages](https://usagi-dead.github.io/frontend-test-att/)

### Стек
Делал всё по ТЗ на чистом стеке, без тяжелых UI-библиотек.
- HTML, SCSS (БЭМ-нейминг).
- Vanilla JS (ES6+).
- Vite для сборки.
- Air Datepicker для календаря (взял его, так как он легкий и без лишних зависимостей).

### Что реализовано
- **Адаптив:** от 360px до десктопа. Карточки, сетка и форма перестраиваются строго по брейкпоинтам из макета.
- **Логика на JS:** 
  - Кастомный слайдер отзывов с нуля (отступы считаются динамически, на ресайз окна повешен debounce).
  - Рабочее бургер-меню (при открытии блокируется скролл body).
  - Сворачивание/разворачивание длинного текста в отзывах.
  - Плавный скролл к расписанию.
- **Доступность:** всем кнопкам и инпутам прописаны hover и focus-visible состояния.
- **Форма:** базовая обработка (сбор данных с полей ввода и календаря, выводятся в alert).

### Как запустить локально

1. Клонируем репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИК/frontend_test_att.git
   ```
2. Ставим пакеты:
   ```bash
   npm install
   ```
3. Запускаем dev-сервер:
   ```bash
   npm run dev
   ```

Для сборки проекта в продакшен: `npm run build`. <br>
Результат появится в папке `dist/`.
